## What this is

A `.pka` is a Packet Tracer *activity* file (a `.pkt` network plus activity/grading definition). The file name suggests an FSNA "SQC" activity, but its contents could not be inspected: Packet Tracer files are proprietary and encrypted/obfuscated, and the header is not a readable or standard archive format. The topology, devices, addressing, tasks and scoring are therefore **not documented here**; open the file in Packet Tracer to see its instructions.

## How to open

1. Install Cisco Packet Tracer (free via Cisco Networking Academy).
2. Use **File > Open** (or double-click the `.pka`) and select `TYLER DAVIS FSNA SQC.pka`.
3. Read the activity instructions via the **Activity Wizard / Instructions** window, if the activity provides one.

The file may require a Packet Tracer version compatible with the one that created it; the creating version is unknown.
